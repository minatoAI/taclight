## 4. 候选排名(同批真实向量)

- **chaser / chaser0**:纹波最低(0.5-1.5°)但稳态滞后 -6°~-16°(光斑持续落后头部)
  → 维持 09-01 结论:**淘汰**(方向误差比闪烁更不可接受)。
- **snap**(无超前):纹波 0.84-5.0°、jumpMax ≤6.1°,但放弃超前 = 回退"转动滞后"老问题。
- **snap+pred(推荐)**:基角弃用 O/C 交叉插值、直接跟随 C 快照(消源1 tick 边界锯齿)+
  保留方案A 速度 EMA×1.25tick 超前(保滞后补偿)。纹波稳定砍 **52-69%**、
  尖峰约减半。#8 大幅扫会话 jumpMax 仍 10.4° → 实施时用本批真实向量做参数扫
  (超前 tick 数/输出 τ/snap 门限),TDD 契约钉死。

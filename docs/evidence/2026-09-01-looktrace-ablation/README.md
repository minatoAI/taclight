# 09-01 · 边缘闪烁消融工具链 + 受控实验(第一轮)

> 目标(用户指令):针对"远程光旋转/移动时边缘闪烁"设计调试工具与消融实验,定位根源,
> 再从已知信息分析解决办法。本轮交付 = 工具链 + 受控实验 + 机制判定 + 方案分析;
> 修复实现待用户批准。

## 一、工具链(全部自研,零依赖)

1. **信号探针 `!looktrace [on|off|帧数]`**(LookTrace.java + uploader 胶水):
   逐帧全量记录角度链路 `t/pt/hO/hC/bO/bC/pO/pC/base/om/ext`(最近非自身 LivingEntity),
   默认 7200 帧自动停。契约 LookTraceContract 钉死格式/窗口/目标切换(AllContracts 全绿)。
   既有 `!extrap log` 是 >0.5° 门控采样,会混叠,不能当消融底座。
2. **消融分析器 `tools/lookreplay.js`**:一份 trace 回放全部管线配置对比:
   raw(原始 20Hz 阶梯)/ lerp(坑36)/ lerp+pred(现行默认)/ **snap(快照插值,修复候选)**/
   snap+pred / chaser(临界阻尼追随器,对照臂)。指标 = 高频纹波(去 150ms 趋势残差峰峰,
   注意裁两端半窗防斜坡截断伪影)、tick 边界跳变、20Hz 频带幅度(Goertzel)、墙面 cm 换算、
   O-滞后分布(机制判定)。自测 8 项 `TOOLS-LOOKREPLAY SELFTEST PASS`(含 Goertzel 已知答案、
   ext 回放恒等 1e-14)。**按 START/END 标记分会话解析 —— 同日志多轮采集拼接会产生假边界
   (实测踩过:跨会话拼接曾伪造 14.06° "异常")。**
3. **实机验证**:单实例 + 盔甲架/僵尸/村民,8 个采集会话全部端到端成功。

## 二、受控实验与机制判定

- **场景**:僵尸追村民(双方持续移动,头部每 tick 真实更新)→ 会话 #8:7200 帧 / 4.2s /
  净转角 -109.2° / 61 个 tick 边界。
- **判定 1(连续转动,非玩家实体)**:O-滞后(hO_new − hC_prev)**61/61 全零** —— 连续转动
  下 O/C 对是良性的,坑36 公式在 zombie 身上无锯齿。**用户真实鼠标的每边界 ±2-3° 锯齿
  未复现** → 源 1 触发条件收敛到玩家实体特有因素(双通道同步干扰 / ±180° 回卷邻近
  —— 用户锯齿恰发生在 yaw≈±180)或其组合;待 mp-session 对远程玩家采集钉死。
- **判定 2(样本台阶的真实大小)**:AI look-snap 单 tick 达 **16.51°**;/tp 阶跃按
  lerpSteps 分 3 tick 收敛(4.69°/tick)。原始阶梯(raw)jumpMax=16.51° →
  **snap 0.43°(33×)**、chaser 0.41°。snap 把任意大的样本台阶摊到 50ms 段内平滑播放,
  且构造上不碰 O/C 对 → 对源 1 全部已知形态免疫。
- **判定 3(帧率真相)**:bench 实测 **1788fps** —— `maxFps=260` 在原版语义=无上限(滑条
  顶格),从未真正封顶。探针窗口按帧数计,时长需按实测帧率换算。

## 三、解决方案分析(已知信息 + 回放数字)

| 方案 | 原理 | 消融数字 | 代价 |
|---|---|---|---|
| **A. snap+pred(推荐)** | 用自己的 C 历史做分段线性播放(滞后固定 1 tick),速度 EMA(τv≈150ms)×超前 | jumpMax 16.5→0.43°;自测纹波 0 vs raw 1.81°;净超前 ~0.24-0.5°(τout 吃掉一部分) | 光斑与头部模型微脱开(头部自身在抖,不可感);tick 抖动→亚 0.1° 级 |
| B. 只调 τ(0.08→0.25) | 慢化现有 EMA | 纹波约 3.52→~0.9°(估算) | 不解决源 1;起停滑行变长 |
| C. 临界阻尼追随器 | 二阶滤波 | 纹波同样小 | **恒速滞后 2v/ωn**(40°/s 时 8°),超前填不平 —— 自测淘汰 |
| D. off | 退回坑36 | 无纹波 | 滞后回归(方案A 前状态) |

**推荐 A**:同时消源 1(免疫 O/C 异常与样本台阶)与源 2(速度 EMA 慢化),保留方案A 的
超前补偿;纯 JVM 可测(本包 trace 即测试向量)。

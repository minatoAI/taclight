## 结论:旋转闪烁 = 两个独立抖动源的叠加

### 源 1:基础角 20Hz tick 边界锯齿(**先于方案A 存在**)

- 坑36 同源插值后的 base 角(truth 列)在 **tick 边界前跳 +2~3° 又回退 ~2°,周期精确 50ms**
  (见 `dev-worst-segment-21-38-47.txt`:47.122→47.123、47.173、47.223、47.272 四个边界)。
- `rotLerp(pt, yHeadRotO, yHeadRot)` 理论上边界连续(O:=C),实测违背 → 疑原版
  yHeadRotO/yHeadRot 更新时序或双通道(RotateHead 包 + Move/Rot 包)叠加;机制待探针钉死
  (反编译源不在本地缓存)。
- 该公式与**原版头部渲染同源** → 头部模型同步微振 = 用户观察到"头/晕转动同步"的原因;
  同样的 ±2-3° 抖动,头部有纹理被视觉掩蔽,光斑软边缘被放大成"边缘闪烁"。

### 源 2:方案A ext 纹波(**08-31 新增,叠加项**)

- ext = EMA(20Hz 量化 ω̂ × ticks),EMA τ=80ms 每 50ms tick 向目标收敛 46%
  → ω̂ 的 20Hz 台阶几乎直通到光斑角度。
- 实测(dev 端默认 1.25):稳态扫视段 ext 峰峰 **3.52°**(21:38:47,0.5s,55 样本,
  ext 方向翻转 1.9Hz = 真摆动非单调爬坡);另一段 1.66°(21:38:27)。
- B 端因 21:07:37 被中继误设 `!extrap 2.0`(旋钮不持久化,重启回 1.25)放大:
  稳态段 ext 峰峰最高 **8.71°**(21:37:50,2.3s)。
- ω 列同时显示 20Hz 台阶结构(1.88 恒定窗 → 2.03 → 3.02 阶梯跳变)。

### 换算与既往验证为何漏检

- 6.5m 墙面:1° ≈ 11cm → dev 端 3.52° 峰峰 ≈ **40cm 光斑边缘晃动/半秒**,可见闪烁实锤。
- 此前四类验证全踩不到"连续快扫":静止(ext=0,像素恒等✓)、直走(ω=0,ext=0✓)、
  /tp 阶跃(传送风暴 ±16° 淹没)、用户坑36 复测(步态/慢转为主,锯齿幅度∝转速)。

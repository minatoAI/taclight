# 位置链移动闪烁:定位与修复(2026-09-01 深夜③)

用户报告:扫视闪烁经 snap+pred(28e1ba2)修复后,**光晕在平移/缩放(位移)时仍有边缘闪烁**;
要求设计移动循环、多轮消融、定位根因后修复。

## 结论(TL;DR)

1. **病灶 = 位置同步链本身**(与旋转链不同源):灯锚点 `getEyePosition(pt)=lerp(pt,o,C)`
   与身体渲染同式,但 o→C 逐 tick 增量有 ±20% 速度调制(20Hz 包节奏 × 缓动除数 3→2→1),
   墙光斑 1:1 放大。方向链(基角+ext)在视角锁死时贡献 = 0,旋转链两轮消融
   (`!extrap off`/`!bsnap off`)三轮数字不变 —— 方向链彻底排除。
2. **修复 = RemotePosSnap 死推滤波**(显示按平滑速度 v̂ 积分 + 每 tick 误差小比例校正):
   稳态步行中段光斑晃动 disp **4px(纵深)/30px(平移)**,旧管线 **6-7px/45-50px**;
   且 disp 为单向平滑追赶,无旧管线的 20Hz 前后跳变(人眼最敏感成分)。
   起停瞬态有界(≤0.35 格)且平滑。契约 21 项 + AllContracts 全绿。
3. **v1(对同步目标 lerpX/Y/Z 做延迟段快照插值)实机 A/B 反而更糟(+27~41%),已否决**:
   实测 lerpX 是突发式台阶(单步 ~0.43 格,≈2 tick 位移一次到),不是匀速序列 ——
   忠实回放突发 = 更噪。教训:**速度调制必须用匀速重构消,任何"忠实回放样本"方案都无效**。

## 定位过程(用户要求:先消融、后修复)

### 第一轮:tp 步进循环(0.3 格/步,平移+纵深各 12 步)
三轮消融(基线 / `!extrap off` / `!bsnap off`,B 端 mcap 自动采集 LOOKTRACE 行):

| 轮 | 配置 | 平移光斑晃动 |
|---|---|---|
| s0025 | 基线 | 0.3473 格 |
| s0027 | extrap off | 0.3487 格 |
| s0029 | bsnap off | 0.3460 格 |

→ 三轮完全一致:旋转链(基角+外推)对移动闪烁**零贡献**;0.347 ≈ 步进粒度自身
(0.3 格台阶被 o→C 忠实回放)= **刺激伪影**,不能代表真实步行 → 换刺激。

### 第二轮:真实 WASD 步行(键盘按住消息驱动 Dev,同步链输入与用户走路一致)
12 次步行(纵深 W/S ×3 + 横移 D/A ×3,每次 ~2.2s/约 150-190 帧):

- 平移会话光斑残差 **0.219-0.230 格(≈53px)**,位置链贡献 100%,方向链 0
- 纵深会话光斑位置残差 ≈0.008-0.012 格(纵深晃动主要表现为缩放抖动)

注:后续以 0.5s 去趋势窗重新标定,真实步行平移全程残差 0.41-0.55 格(≈100px);
之前 53px 低估(旧分析器去趋势窗单位 bug)。**用户主诉量级确认。**

### 修复演进
- **v1 快照插值(lerpX/Y/Z)→ 实机更糟**(psnap on 平移残差 0.52-0.73 vs lerp 0.39-0.53):
  lerpX 实测为突发台阶(p50 间隔 16.7ms、单步最大 0.428 ≈ 2 tick 位移),假设错误。
- **v2 死推+速度导引 → 实机改善**(同输入 A/B,`!psnap off/on`,disp 列=管线实际值):
  - 全程残差:平移 0.43-0.49 → 0.32-0.39(−18~24%);纵深 −18~30%
  - **步行中段纯稳态**:disp 误差 p2p = **0.016-0.018 格(4px,纵深)/ 0.125-0.145 格(30px,平移)**,
    对应 lerp 臂 6-7px / 45-50px;且误差为有界缓变,无向后跳变
  - 起停瞬态:有界 ≤0.35 格、单向收敛(契约 5/6 钉死);急停滑行由超前钳制封顶 0.08 格

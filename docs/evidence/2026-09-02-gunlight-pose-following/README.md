# 2026-09-02 · 枪灯枪姿跟随:坑60 修复 + 实机验证(腰射/疾跑)

## 结论

**枪灯现在精确跟随枪械姿态。** 本轮三件事:①`/taclight kit` 经 TaCZ 官方 API
`IGun.installAttachment` 预装枪灯(此前发散件需改装 UI 手动装,自动化做不了);
②修 坑60——枪口姿态"视图→世界"换算用共轭,方向恒为 −look(灯照向身后上方);
③实机验证:腰射灯池在枪口指向的前下方,疾跑枪横持、灯池整体甩向左上方。

## 根因(坑60,详见坑位册 §6 条 46)

- 捕获链本身正确:BeamRenderer 注入点在骨变换之后,矩阵=骨局部→枪渲染空间;
  stringVertex 顶点(z=length 沿 −Z)证明光束沿骨局部 −Z、TaCZ 自渲染激光方向正确。
- 错在上传器:`cam.rotation()` 是 MC 约定(+Z 为前),枪渲染空间是 GL 视图(−Z 为前),
  正确换算 = **Q_cam · Ry(180°) · v**,旧实现用 conjugate。
- 实测钉死(修复前 DIAG):上传 dir=(0.003, 0.434, 0.901) vs look=(0,−0.423,−0.906)
  精确反向;灯位在眼后上方 1.5m。

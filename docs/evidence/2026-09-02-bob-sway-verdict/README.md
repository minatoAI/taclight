# 2026-09-02 · bob 晃动判决:影子 vs 世界特征同帧摆动测量 + 数据流定案

## 结论

用户判决实验(出厂功能下):关视角摇晃→步行条纹消失,摇晃开→复现;跳跃(原版 bob
振幅离地衰减)→明显减轻。**视角摇晃=唯一触发条件,定案。**
用户假说"自身视角摇晃被错误作用到他人光源(延迟补偿过冲)"**被数据排除**:

1. **延迟补偿消融**:双端 psnap/bsnap/extrap 全关(04:11 日志回显)后步行,条纹
   依旧;恢复默认后关 bob,条纹消失——假说两个方向都不成立。延迟补偿输入=网络
   实体数据,1.20.1 bob 只进投影矩阵,数据流无交点。
2. **光位恒定**:ABBA s0005 全程 238 采样,L0 pos/dir range=0(evidence/
   2026-09-02-dda-bob-stripe/);本日 03:52 与 04:11 DIAG 快照逐位相同(间隔内
   用户持续行走)。光源在世界系不动 → 其影子图案在世界系静止。
3. **摆动幅度=相机重投影量级**:s0005(bob on+voxel on,B 行走看 Dev 静止灯)
   81 帧逐帧亚像素跟踪(sway-track.js):影界横向摆动 rms 6.68px(y320)/6.99px
   (y400);世界特征(石柱暗面 3.53/6.66px、砖缝 5.36px)同量级;按 bob 公式
   (±0.05~0.075 格 @3-5m)预测屏幕摆动 ±5-11px——吻合。影界/石柱比 1.34 由
   掠射角放大解释(影界沿视线方向躺在地面,单位相机位移的屏幕扫动天然大于
   正面立体的棱边;投射几何,非 bug)。
4. **测量分辨率声明**:特征跟踪噪声底 ±3px(胶片颗粒+低对比亚像素),无法分辨
   <3px 的差分;但"光链 bug"假说需要 bob→光源世界系效果的通道,该通道已被 1/2
   封死,故定案不依赖第 3 条的精细比值。

## 机制(费曼版)

bob = 相机以步频平移 ±5-10cm+微转。世界(含静止光源与其影子)不动,画面整体
以步频重投影:远近不同位移不同(透视呼吸)。影子边界是全场景对比度最高、视角
最掠射的图案 → 同样的相机位移在它上面最显眼,表现为"条纹随步频脉动放大"。
影子看起来"晃得比世界多"= 对比度+掠射角显著度,不是位移量不同。

## 改进空间(与用户讨论中)

- **自己举灯**:灯锚/灯向跟随 bob(头灯物理)可让近场锥体随视线稳定——候选
  `!lanchor bob` 消融旋钮(需新代码,TDD)。
- **看别人的灯**:世界静止灯的影子随观察视角晃=物理正确,渲染端无正当消除手段;
  现实选项=关视角摇晃(原版辅助选项,正当)/加宽 FUZZ 降对比(已 0.35)/接受。
- bloom 是否放大脉动感:可用 DBG5 隔离验证,若显著可另立小项。

## 结论

1. **旧 verdict"注入未渲染"推翻**:枪/手持两路注入在 Comp 里都渲染,`!bright` 缩放即铁证。
   旧判错因三条:冻结默认 bright 6 太暗(+3.9 灰阶,被 Comp tonemap 淹没);`!light`
   只管手持不管枪(交接 §2.3 的 A/B 拨错了灯);跨包像素对比被 tonemap 污染。
2. **双关残留池 ≠ 注入**:双关时 DIAG ssbo count=0,池仍在;空手消失。身份=
   TaCZ 原生激光(`gun_light_display.json` 自带 `"laser"` 块,暖白 18 格),
   配件在手即渲染,与 SSBO 开关无关。`!light/!gun` 管不着它。
3. "关不掉的手电"(用户截图圆斑压准星)=**我们自己的枪灯**:当时 `!gun manual=true`
   (诊断复原遗留) + 枪灯不校验枪在手(L 只管手持)。已灭(`!gun off`,ACK 双关)。
   修法见 2026-09-07-gunkey-specknee 包(M 键 + `!gun auto`)。

判定:注入活,旧负结果口径作废;`166.5fps`仍不得引用为注入成本(无效果帧)。

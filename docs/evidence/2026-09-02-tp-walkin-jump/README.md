# 2026-09-02 步行入场光晕跳变:打桩定位 → 局部偏移重构跟随 → 坑78 投毒防线 → 回归闭环

## 现象与结论

用户报告:ObserverB 静止,Dev 开灯站在 B 视野外;Dev 向前步行进入 B 视野的瞬间,
B 视野中的光晕位置出现一瞬间的卡顿和跳变。

**结论 = 代码缺陷(两层)**:①fallback 锚=眼位+0.45·视线近似,与真实枪口差
~0.75 格,枪模入视锥后该差量在 200ms 内分帧兑现(追赶滑落);②旧 referent 稳态
门禁把"位置"当失效条件,步行即破 hold。修复 = **局部偏移重构跟随**:捕获给出
"枪口−眼位"局部偏移(前/上/右),绕实时偏航旋转加到实时 psnap 眼位——平移
(步行/坠落/传送)由重构吸收,只有姿态(偏航/俯仰/瞄准/手持)变化才降级。

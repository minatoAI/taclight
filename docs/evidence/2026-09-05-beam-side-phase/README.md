# 2026-09-05 体积光"侧面服务型"相位(丁达尔定案)

## 需求(用户三轮收敛)
1. 侧视轮廓还是暗淡 → 侧面提亮;
2. **正对光源时体积光与表面光叠加太亮 → 正面调低**;
3. 定案原文:"体积光只需要给侧面视角服务,主要是实现丁达尔效应的效果,强化旁观者的视觉感受"。

## 改动(替换 HG 相位)
- composite1.fsh:`phase = TACLIGHT_BEAM_NORM·(f + (1−f)·sin²θ)`,θ=视线×光传播。
  **正侧 90° 最亮(丁达尔),正对/沿轴(0°/180°)只剩底亮份额 f**;
  `TACLIGHT_BEAM_NORM 0.4`(实测定标),f=vlParams.x(Java 侧 `BEAM_SIDE_FLOOR=0.04`,`!scat` 透传,0=纯侧面)。
- taclight_math.glsl:taclight_hg 移除(全库仅 composite1 一处消费);glsl 注释同步。
- 旋钮语义:`!scat` 从"HG 各向异性 g"改义"轴向底亮份额 f"(区间 0..0.9 不变,回显/knob 帮助同步)。
- 契约:LightTune 88(实为 90,计数串本次修正)→ **93 项 ALL PASS**;ShaderCore 改钉"hg 已移除"。
- 亮度对账(替代 HG g=0.55,每采样相位):
  | 视角 | 旧 HG g=0.55 | 新 phase | 效果 |
  |---|---|---|---|
  | 正侧 90°(旁观者) | 0.0373 | **0.4(实测光束项 +~32/255)** | 侧面丁达尔成型 |
  | 沿轴 0°(持灯者前向) | **0.609** | 0.016 | 持灯者视轴 −28% 亮度 |
  | 正对 180°(迎面看灯) | 0.0149 | 0.016 | ≈持平,不增反略降 |

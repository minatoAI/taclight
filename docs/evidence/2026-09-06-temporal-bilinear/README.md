## ① 条纹修复(查表双线性化)

机制:表 = 512×256 equirect,每 texel 0.7° 扇形存一个"最远无遮挡距离 D",
30m 处扇形横跨 ≈37cm,**超过 FUZZ 0.35m 软化带宽度** → NEAREST 取值下相邻扇区
vis 整带跳变 = 用户看到的径向条纹。双线性 4tap 把台阶变为跨一个 texel 的连续
插值(经度接缝 mod 环绕、纬度钳制),等效角度分辨率 ×2。

实机同姿态 A/B(柱影场景:`14.19.06.png` 立柱制造径向阴影边,锥 20,4K):

| 对比 | meanDiff (/255) | changed | 判定 |
|---|---|---|---|
| occl on(表+**双线性**)vs occl off(逐采样 DDA 精确解),14:19 | **0.0144** | **204px = 0.0025%** | 查表与精确 DDA 已到噪声级一致 |
| (历史参考)occl on(表+NEAREST)vs occl off,12:05 同口径 | 0.894 | 0.16%(有结构性扇区差) | 条纹源 |

meanDiff 降 **62×**、changed 降 **64×**(位形不同不可直接比,量级差自明)。
契约新增 4 组性质钉(OcclTableContract 5263 → **17061** checks):
texel 中心恒等 NEAREST / 双线性凸性(vis ∈ 4tap 邻域)/ 阴影边界 Lipschitz
(±0.01 texel 的 vis 变化 ≤ 邻域梯度界 = 无悬崖)/ 跨界中点严格插值。

## ② 时间复用(!tm,默认开)

设计(用户批准的"时间复用"立项;半分辨率路线已被本包史否决——v0.10.0 热修,
Oculus 1.8.0 buffer 全屏假设不成立,故为全分辨率减步):

- composite1 步数 tm 开 64→**32**,IGN 抖动加逐帧旋转(`fract(ign + 0.618·frame)`,
  帧间去相关,时间累积才能回质量);
- 上一帧历史存 **colortex9**(clear=false,rgb=混合后光束,a=march 终点距离/256);
- 重投影:当前像素终点经 **gbufferModelViewInverse 全逆**(铁律 3,抵消 bob)→
  绝对 world → previousCameraPosition → 上一帧全矩阵回投;相机运动精确对齐;
- 有效性门:历史 a>0 且非 NaN + 重投影 uv 出界拒用 + 终点距离差 ≥2m 拒用
  (disocclusion);
- **逐灯置信度**(防拖影):Java `LightMotionConf` 按灯身份键(自身手持/枪、远程按
  实体 id)差分上帧位姿,`conf = exp(-6·Δpos)·exp(-4·Δangle)`,经 SSBO vlParams.w
  (原恒 0 保留槽,布局 96B 不变)透传;首帧/灯开关/瞬移 = 0 = 全新鲜。
  GLSL 混合权重 = 0.75 × conf(贡献灯取最小;无贡献像素 conf=0 → 灯关即灭);
- `!tm off` = 64 步全新鲜(逐位旧行为,A/B 保底)。

## 方法论备注

- 空间映射求解:枚举候选旋转 {I, Q, Q·Ry180, Q⁻¹, Q⁻¹·Ry180} × 方向源
  {±raw, ±col2},以 DIAG-REMOTE 实测 Dev 位置+eye 高度+look 为地面真值打分。
- joml 语义坑:Vector3f.rotate 对非单位四元数做归一化真旋转;与"单位假设展开式"
  在 3 位舍入输入下差 0.05%——契约钉值必须贴运行时库输出(差异 7mm 级,判别余量 12 格)。
- 亮度判定用 tools/.session/luma-probe.ps1(System.Drawing 逐像素),禁目测。

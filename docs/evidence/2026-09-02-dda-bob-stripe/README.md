# 2026-09-02 · 移动时地面条纹随视角晃动节律放大:根因定位 + DDA tie/软化带修复

## 结论(一句话)

用户看到的"地面条纹"是 **体素 DDA 算出的墙柱硬影(正确的遮挡输出)**——SSO 时代
同区域漏光把柱影糊掉所以不可见;**"随观察者视角晃动有节奏放大" = 硬 0/1 影缘在
行走 bob 的亚像素视差下成片翻转/闪烁**。修复 = ①DDA tie 语义(同一 crossing time
的全部轴一次推进,消除擦边假阴影格,契约 20 项钉死)+ ②实心格穿透软化带
`TACLIGHT_VOX_FUZZ 0.20`。实机四臂 ABBA(同场景同步行输入):bob 锁定亮度脉动
p90 残差 RMS **34.1 → 20.2(−41%),|bob| 相关 0.41 → 0.17**;墙后漏光回归
**82.1(off) → 44.3(on)= 无灯基线**,直射池 off/on 逐位恒等(64.5),bench
59.8fps/1%low 55.9 与 09-01 持平。**待用户体感验收**(带宽 0.20 是单常量旋钮,
嫌影软可降 0.12,仍有节律可升 0.30-0.40,`!reload` 即生效)。

## 排查链(为什么走这么远)

1. `!rec` 可信录制器(前一里程碑 d9a0017)+ 新增 `!bob` 调试旋钮 → 首次能做
   同输入四臂消融。
2. bob×voxel 四臂(原始构建 s0006-09):只有 on/on 臂异常 → 交互确认,但整段
   极差被走近/走远大尺度趋势污染。
3. tie 红灯(单轴分轮会访问射线仅擦边的侧邻格)→ 修复 → s0010-13:p90 残差
   34.1→27.5,|bob| 相关 0.41→0.18——**方向对但不彻底**。
4. 加穿透软化带 0.08(fuzz08 s0001-04):p90 残差 30.8——**无改善,硬边假设
   受挫,停止加码,回到帧证据**。
5. 帧证据三连(关键):
   - 同位置反 bob 相位帧对:全帧 19% 像素差>8 —— 但同相位相邻帧对 25%,
     **被 final 通道胶片颗粒(每帧随机 ±10)主导,原始差分不可用**;
   - 相位平均差分(同位置分箱,driver>0 vs <0 分别平均再减):A1 与 B1
     **逐 bin 几乎相同** → bob 锁定的图像变化与 voxel 无关,不是时间性脉动;
   - p90 波形逐帧打印:u≈2.9 处 A1 有 **214→63 的空间悬崖**(前进/回程同位
     置一致),B1 只有 212→160 的缓坡 —— cubic+方向去趋势吃不掉陡崖,残差全
     落在悬崖两侧且与步行相位相关 → **|bob| 相关是位置混河出来的假象**。
6. 帧目检(×3 提亮):A1 地面 = 亮暗相间竖条纹(墙柱硬影),B1 同区域整片亮
   (SSO 漏光);走近后条纹移出视野、柱影区全黑 —— 与用户"条纹随视角晃动节
   奏放大"的体感吻合:条纹是 DDA 的新正确输出,节律闪烁是硬影缘的运动混叠。

## 修复语义(两处,均契约钉死)

- **tie 全轴推进**(`taclight_vox_transmit` + `VoxelDda` oracle):旧实现按
  X→Y→Z 单轴分轮,射线恰好同时跨两面/三面时会检查仅擦边、并未真正穿入的侧
  邻格 → 假阴影格随 bob 成片翻转。现在以统一 crossing time + 距离比例容差
  (`max(1e-6, |t|·1e-6)`)一次推进全部 tied axes。
- **穿透软化带** `TACLIGHT_VOX_FUZZ 0.20`:实心格内按射线穿透长度放行,
  ≥0.20 格仍一票否决 T=0(墙后遮挡内部不变),掠边按比例部分透射 —— 等效给
  影缘一条 0.2 格半影,把 bob 视差(3-5m 处 1-2.5cm)的采样跳动从"全幅翻转"
  压到"半影内小幅滑动"。0.08 实测不够(边缘 |bob| 相关仍 0.13),0.20 将
  p90 脉动砍 41%。
- 树叶 0.40/植被 0.75 整格语义不变;终点豁免、负方向、格面起点、128³ 边界
  契约全绿(`VoxelDdaContract` 20 项,含 GLSL 源码字符串契约防漂移)。

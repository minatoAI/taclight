# 2026-09-05 体积光束可见性诊断(beamonly 下"看不到丁达尔")

## 问题
用户在 Dev(A 端)视角观察 ObserverB 的手电光,`!beamonly on` 后看不到体积光/丁达尔效应。
问:调试开关的问题,还是体积光实现不对?

## 结论
**开关没问题,实现没问题——是"侧面看水平光束"的可见性被四个机制联合压死。**

## 判定实验(全部实机截图,`!shot` 抓帧;机位/参数见各图)

## 四机制(为什么侧面看不到)
1. **HG 相位角**:g=0.55 前向散射,phase(θ)=(1−g²)/(4π(1+g²−2g·cosθ)^1.5):
   θ=0°(顺轴)0.609、θ=90° 0.037、θ=117°(本机位偏背射)≈0.023 → 侧/背视比顺光暗 **16~27×**。
2. **FOV 几何**:水平光束与视线夹 ~63°,在 70° FOV 内只剩近端 ~2.5m 的细锥段
   (锥半径 ≤1.6m),粗而亮的远段全在画面外。
3. **raymarch 步长**:composite1 全屏固定 32 步;视线背景为远距离时(天空 maxDist=96 →
   步长 3m;掠地 30~60m → 1~2m)细锥在两采样之间被跨过;IGN 抖动(±0.35 步)只去条纹
   不补能量。02 图光扇之所以可见,恰因照地时视线沿锥体掠过 10m+ 长路径(采样足、路径长)。
4. **能量**:密度默认 0.05(`!beam off` 回默认);用户调到 0.2 仅 4×;K=5 衰减在 0.5r
   (r=17.1 → 8.5m)处只剩 20%。

## 复算
- 相位值代入上式即可复算(g=0.55)。
- 每条视线贡献 ∝ intensity × spot × atten × phase × density × (锥内采样数/32) × BEAM_GAIN(0.5),
  与 composite1.fsh 逐项对应。

## 改进提案(待拍板,未实施)
- **A. `!scat` 第六旋钮**(g,0..0.9,经 vlParams.x 透传):g=0.2 时侧视相位 0.037→0.072
  (≈2×),代价顺轴光球 0.609→0.149(−4×)。适合"侧视可见"优先的观感。
- **B. TACLIGHT_VL_STEPS 32→64**:远背景步长 3m→1.5m,细锥采样翻倍;成本 composite1
  ~0.25ms→~0.5ms/帧(395.5 vs 439.2fps@32 步基准外推,待实测)。
- **C. 现有实现即可用的观察配方**:B 照地方向 + 侧后看光扇(图 02 形态);或
  `beam 0.5~1.0 + bright 12~20 + atten 2` + 顺轴看光球(图 05 形态)。
- **D. 窄锥角**(现半角 32°/18°,per-light 数据):"细光柱"形态的根本前提是窄锥,
  属 config/灯数据改动,另立项。

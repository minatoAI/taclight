## 0. 一图流:一盏灯从开关到屏幕

```
Java 模组(每渲染帧)                       GLSL 光影包(taclight-shaders-dev)
┌────────────────────────────┐            ┌─────────────────────────────────────┐
│ 收集灯:自己(本地状态)      │  SSBO      │ gbuffer     画几何,留深度/法线/反照率│
│ + 远程玩家(同步数据+外推)   │ ─binding=7─▶ composite     表面照明(M1):逐像素     │
│ 钳制灯头出实心 → 上传        │            │               给被照面加光          │
│ 每灯一槽 21 个 float:       │            │ composite1    体积光束:全屏 raymarch│
│   pos+radius               │            │ composite2    bloom一级+自动曝光     │
│   color×intensity          │            │ composite3    bloom二级(大半径)     │
│   dir+类型位               │            │ final         合成→曝光→AgX→gamma   │
│   cone(cos外,cos内,K,G)  │            └─────────────────────────────────────┘
│   vlParams(相位,密度,m,…)│
└────────────────────────────┘
```

要点:**灯的所有参数经 SSBO 每帧重传,旋钮零重启生效**;GLSL 端按物理公式消费。
`!xxx` 旋钮改的是**查看端**的上传数据(见 §5 的"作用域"——这是实测最容易踩的坑)。

## 1. 表面照明的五个参数(灯打在墙上/地上的那部分)

单个像素收到单盏灯的贡献(线性域,composite M1):

```
radiance贡献 = knee( (albedo·ndl·漫反射 + 高光) × intensity × spot × atten × vis )
```

五个因子各管一件事,**亮度问题先判断是哪个因子错**,再动对应旋钮:

### 1.1 intensity(亮度)——`!bright <0.5..30>`,config 默认 6.0
线性乘数,直接进上式。它还**耦合照距**:有效半径 = config 半径 × √(intensity/6)。
→ "只想要亮不想照远"必须配合 `!dist`(bypass 耦合)或压 `!atten`。

### 1.2 radius(照距)——`!dist <4..96>`,config 默认 36(亮度 6 时)
硬截断:d > radius 的像素直接无光(廉价门)。同时是衰减公式的归一化尺度(见下)。

### 1.3 atten K(衰减)——`!atten <0.2..20>`,GLSL 默认 5.0
平方反比的软化版,归一化到 atten(0)=1、atten(radius)=0:

```
atten(d) = [ 1/(1+K·(d/r)²) − 1/(1+K) ] / (1 − 1/(1+K))
```

实算(K=5,r=36):0.25r(9m)→**71%**,0.5r(18m)→**33%**,0.75r(27m)→**11%**,r→0。
K 越大远处暗得越快(2 ≈ 0.5r 处 50%,常用日常值;5 = 主包标定;20 = 手电聚光感)。
(源码注释"5.0=0.5r 处 20%"是旧口径,按现行公式实算 33%,以本表为准。)

### 1.4 spot(锥角)——`!cone <2..45>`,config 默认外角 8°/内角 4°
```
spot = smoothstep(cos(外角), cos(内角), cosθ)   θ=光轴与灯→像素夹角
```
内角内全亮,外角外全灭,之间平滑。**这是"接近平行光"的旋钮**(2026-09-05 由 32°/18°
收窄,用户报"远距离显得范围巨大"):光池半径 ≈ d·tan(外角),

| 距离 | 旧 32° | 新 8° |
|---|---|---|
| 5m | 3.1m | 0.70m |
| 10m | 6.2m | 1.41m |
| 30m | 18.7m | **4.2m** |

`!cone 8` 内角自动 = 外角一半,只露一个参数。

### 1.5 knee G(近场软膝)——`!knee <0.2..8>`,默认 **2.0(出厂即开)**
```
f(x) = x / (1 + G·x)
```
逐灯、在求和**之前**施加。解决两个物理事实:
① 平方反比近场发散(1m 处贡献是 10m 处的 100 倍),HDR 值进 bloom 会白爆刺眼
(用户截图 2:Dev 站进 B 的光束,视野内反光爆白);
② 压近不压远:x 小(远场)时 f≈x 零损失,x 大(近场)被压向上限 1/G。
实算(亮 12、K=2、白墙):7.5m 处线性贡献 5.6 → G=2 压到 0.46、G=8 压到 0.12;
实机光池核显示均值 189(G2,饱和近白)→ 106(G8),对照远墙 ratio=1.00(远场零变化)。
**近场眩光第一旋钮就是它**(4~8 更狠;`off` = 回默认 2.0)。

### 1.6 vis(遮挡)——`!voxel on/off`,默认 on
1 格 = 1 体素占用栅格(与 block.properties 同源),灯→像素 DDA(徐昊-Amanatides-Woo)
逐格步进:实心 = 挡死;树叶透射 0.40 / 植被 0.75;FUZZ 0.35 格软化带治掠边闪烁。
灯头被推进墙体时会自动沿反方向退到首个非实心格(穿墙修复),三路消费共用一处。
`off` 回退旧深度缓冲法(仅自遮挡,墙面漏光)。

## 2. 体积光束(丁达尔效应,composite1)

不是"把灯画亮",而是**沿视线做 64 步 raymarch,把光路中每一小段空气被灯照亮的散射
量累加**。每步每灯贡献:

```
累加 += 颜色×intensity × spot × atten × ph(相位) × visVox(灯侧遮挡) × beam密度
最终 × BEAM_GAIN(1.0) / 步数,过重叠软上限,写 colortex4
```

### 2.1 相位 ph——`!scat <0..0.9>`,默认 0.04(**侧面服务型**)
真实气溶胶前向散射强(顺轴亮、侧视暗),但用户定案:**体积光只为旁观者服务**
(丁达尔轮廓),正面亮度与表面照明叠加反而刺眼。故用反常规剖面:

```
ph = 0.4 × ( f + (1−f)·sin²θ )    θ=视线与光传播方向夹角,f = !scat 值
```

- 侧视 θ≈90°:ph=0.4(最亮,老 HG 模型的 ~10.7 倍 → 侧视轮廓从"看不见"到"雾蒙蒙一条");
- 正对灯 θ=0:ph=0.4·f → f=0.04 时 0.016(**比侧视暗 25 倍**);`scat 0` = 正面全灭。

### 2.2 beam 密度——`!beam <0..1>`,config 默认 0.05
散射物质浓度,线性乘数。0.05 是"存在但不喧宾"的底档;要明显光柱用 0.3~0.6,
1.0 = 浓烟感。注意:`!beam 0` 只是视觉归零,**raymarch 循环照跑**(性能见 §4),
"关体积光测性能"要用灯开关而不是 `beam 0`。

### 2.3 重叠软上限——`!beamcap <0.25..8>`,默认 m=1(帽=2.0)
多灯束重叠时累加值无限上探 → 白爆。分量级指数肩部:**≤半帽点恒等(单灯零变化),
超帽平滑渐近封顶**(无硬切色阶)。双灯同照刺眼用 `beamcap 0.25~0.5`。

### 2.4 灯侧遮挡(2026-09-05 本轮修复;2026-09-06 查表化+条纹修复)
体积光的"被墙挡住"分两层:
- **视线侧**(原有):采样点在实体表面之后 → 跳过(深度门);
- **灯侧**:采样点在空气里,但**灯→采样点光路穿墙** → 漏光。现行实现 =
  **遮挡距离表**(方案二):composite 最早段每帧为每灯预建 512×256 equirect
  "该方向首个遮挡距离 D"表(colortex8),采样点一次查表(代替 384 格 DDA);
  查表为**双线性 4tap**(2026-09-06 条纹修复:0.7° 扇形量化在 30m 处 ≈37cm,
  超 FUZZ 0.35 带宽,NEAREST 相邻扇区跳变=径向条纹;双线性把台阶变连续插值,
  实机与逐格精确 DDA 的差异降到噪声级 0.0144/255)。`!occl off` 回退逐采样 DDA。
实机:漏光带 ROI 83.4 → 56.2(=环境基线),侧视光束仍在。

### 2.5 为什么"对着虚空看"没有光束(已知物理,非缺陷)
能见度 = 散射量 × 背景对比。侧视看到光束需要**束后有近景**(墙/地面)承接亮度差;
束后是天空/虚空时能量与路径双输,本来就暗。测试姿势:让持灯者侧对光路、
镜头后方 3~10m 处有墙或地面。

## 3. 色调链:白爆从哪来、谁在哪一环压

```
线性累加(灯+场景) ──M1──▶ shoulder3(×GAIN 2.2, T=0.55) ──▶ colortex0
体积束 ─────────────────────────────────────────────▶ colortex4 ──beamcap 在此上游──▶
composite2:两者相加 → 亮部软阈值(线性 1.0±0.4)提取 bloom一级
          8×3 稀疏网格统计平均亮度 → 自动曝光写 colortex7(时间常数 ~0.3s)
composite3:bloom二级 13tap 大半径辉光
final:(场景+束+bloom×(0.18/0.30)) × 曝光×TONE_GAIN(3.0) → AgX(或 ACES) → gamma
```

- **白爆 = 线性 HDR 值过高**,bloom 阈值在"曝光之后"看仍是高光 → 大半径辉光糊开。
- 治理位置:近场单灯 → **knee**(在 radiance 求和前,治根);多灯重叠束 → **beamcap**
  (在束累加后);整体过亮 → `!bright`↓ 或 `!atten`↑。
- 自动曝光会把画面拉回中灰:夜里开灯显得效果强、白天弱,是曝光在起作用,不是灯坏了。

## 4. 性能:实测(2026-09-06 复测双分辨率,!bench 每臂 3 遍取中位;RTX 5070 Ti)

环境:A 端 Dev 全屏 **3840×2160**(=本机显示器原生 4K;系统"2560×1440"是 150% DPI
缩放的虚拟值)、renderDistance 12、vsync off;B 端 854×480 窗口同 GPU 常驻(与用户
实际"开一个游戏窗口"接近,臂间对比中互相抵消)。

| 臂(同机位,唯一变量) | 854×480(0.41MP) | 3840×2160(8.29MP,20.2× 像素) |
|---|---|---|
| 灯关(灯循环整跳 = 包基线) | 0.592 ms(1690fps) | 7.80 ms(128.2fps,1%low≈110) |
| 灯开+voxel off(无 DDA) | 0.784 ms | 11.16 ms(89.6fps) |
| 灯开+voxel on+cone 8(默认) | 0.782 ms | 11.29 ms(88.6fps,1%low≈73) |
| 灯开+voxel on+cone 32(旧宽锥) | 0.785 ms | 14.10 ms(70.9fps) |

**结论:**
- **TacLight 全部逐像素成本:480p ≈0.19ms → 4K ≈3.49ms**,对 20.2× 像素增长 18.4×
  ≈ **随像素数线性**(按此律估算 1080p≈1.0ms、1440p≈1.8ms——估算值,未单独实测)。
- **4K 下你的真实帧率(默认配方 cone 8/4):≈88fps**(灯关基线 128fps);60fps 目标
  余量充足,144fps 达不到——但瓶颈不全是灯:基线本身 128fps,灯占 11.3ms 帧里的
  3.5ms,其余 7.8ms 是场景/包本身。
- **灯侧遮挡 DDA 默认配方下 +0.13ms(≈4%)**——便宜门 `spot·atten·ph<1e-4` 依然有效;
  **但旧宽锥 32° 在 4K 下暴露出真实代价:+2.81ms(88→71fps)**——宽锥让更多采样通过
  门 → 更多逐采样 DDA。480p 上此项曾是噪声级,"锥角影响成本"是**高分辨率才显现**
  的效应;这也是收窄到 8° 的额外收益。
- 1% low / minFPS 全臂稳定(4K 灯开 70~76),无病理性尖刺;GC/区块加载尖刺与灯无关。

### 4.1 时间复用(2026-09-06 下午,!tm 默认开)——灯开销再减半

步数 64→32 + IGN 抖动逐帧旋转 + 上一帧历史(colortex9)重投影混合(权重=
0.75×逐灯置信度,Java 按灯位姿帧间差分:灯动/瞬移/开关→置信度降→混合降权,
防拖影)。静态场景有效步数 = 32/(1−0.75) = 128。实机(同 §4 机位换远看被照墙,
锥 20,单灯,bench×3 中位):

| 臂 | fps 中位 | 灯光开销 |
|---|---|---|
| tm off + occl on(64 步) | 116.2 | 6.24ms |
| **tm on + occl on(新默认)** | **183.5(+58%)** | **3.08ms(−50.6%)** |
| tm off + occl off(逐采样 DDA) | 106.2 | 7.05ms |
| tm on + occl off | 167.0 | 3.62ms |

画质:tm on 收敛 vs tm off 同机位 imgdiff **changed=0(逐位一致)**。拖影由置信度
机制兜底:快速甩灯时自动降为全新鲜(1 帧噪声级),`!tm off` 即回旧路径。证据
`docs/evidence/2026-09-06-temporal-bilinear/`。

## 5. 旋钮总表(10+2 个,全部零重启)

**作用域铁律(坑 107):旋钮改的是"查看端"上传的 SSBO。要看 A 视角里 B 的灯,
命令必须发给 A 端;发给 B 端对 A 的画面无效。** 自己的灯的表面照明效果,同样由
查看端(自己)的旋钮决定。

| 旋钮 | 范围 | 默认 | 0 与 off 的区别 | 重启 |
|---|---|---|---|---|
| `!bright` | 0.5..30 | config 6.0 | — | 清零回 config |
| `!dist` | 4..96 | config 36 | — | 清零回 config |
| `!atten` | 0.2..20 | GLSL 5.0 | 0=非法 | 清零回默认 |
| `!knee` | 0.2..8 | **2.0(默认开)** | off=回 2.0 | 清零回 2.0 |
| `!cone` | 2..45 | config 8°/4° | off=回 8/4 | 清零回 config |
| `!beam` | 0..1 | config 0.05 | **0=视觉关(循环仍跑)**;off=回 0.05 | 清零回 config |
| `!scat` | 0..0.9 | 0.04 | **0=纯侧面(正面全灭)**;off=回 0.04 | 清零回默认 |
| `!beamcap` | 0.25..8 | 1.0(帽 2.0) | off=回 1.0 | 清零回默认 |
| `!beamonly` | on/off | off | on=跳过表面照明只看束形态 | 清零 |
| `!voxel` | on/off | on | off=回退旧遮挡 | — |
| `!occl` | on/off | on | off=回逐采样 DDA(慢但逐格精确) | 清零 |
| `!tm` | on/off | **on** | off=回 64 步全新鲜(时间复用关闭,逐位旧行为) | 清零 |
| `!lv` | 档位 | — | 与 !bright 互斥,后写者胜 | 清零 |

无参 = 回显状态。全部是**内存覆盖**,不动 config 文件;体感满意后把值固化进
config 默认(等用户拍板)。

## 6. 现象 → 根因 → 旋钮 速查

| 现象 | 根因环节 | 动作 |
|---|---|---|
| 正对灯看太亮刺眼 | 相位设计(正面只剩 f 份额)+表面照明叠加 | `scat 0~0.1`;`beam`↓ |
| 侧面看不到光束 | 束后无近景(物理)或密度低 | 换机位让束后有墙;`beam 0.3~0.6`、`scat`↓ |
| 光束/光斑穿墙 | (已修)灯侧 DDA;若再现=栅格未覆盖回退 | 复现即报,附 `!diag` |
| 站进光束近场白爆 | 平方反比近场 HDR → bloom | `knee 4~8`;多灯再加 `beamcap 0.25~0.5` |
| 远处光池显得范围巨大 | 外角大 | `cone 4~8`(内角自动半角) |
| 名牌/文字周围发白 | 不是名牌亮,是邻近过亮面的 bloom 辉光晕染 | 压根源(knee/beamcap),别盯名牌 |
| 只想看光束形态调参 | 表面照明干扰 | `beamonly on` |
| 光斑边缘闪烁(走路时) | 硬影缘 × 视差采样翻转 | FUZZ 已 0.35;仍见可升 0.40(待立项) |
| 白天灯效弱 | 自动曝光拉高 EV | 物理预期;夜里验收 |
| 调了没生效 | 发错端(坑 107)或没 `!reload`(改 GLSL 时) | 旋钮发给**查看端**;GLSL 改动需 sync+reload |

## 7. 已知边界(不做/待立项)

- DH LOD(≥192m 远景)不吃灯光(照距上限 96m)= 物理预期;
- 体积束的"一根柱"级细窄形态 → 另立项(锥角 8° 已是当前模型下限附近,`!cone 2` 可试);
- 8 灯上限(第 9 盏起静默丢弃);树叶/植被透射系数(0.40/0.75)未做逐材质体感扫参;
- raymarch 64 步对远背景视线步长 1~3m,极细锥远端仍可能有采样欠密(64 步已缓解一档)。

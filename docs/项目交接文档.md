## 3. 架构主线:一条数据通道 + 五段渲染管线

### 3.1 数据通道(Java → SSBO → GLSL)

```
ClientSpotlightUploader.onFrame()          [渲染帧级,RenderLevelStageEvent AFTER_LEVEL]
  ├─ 相机/玩家姿态 + TacLightConfig 参数
  ├─ 第一人称手电: 眼位 + handheldOffset(视线+0.35前 / 右手+0.22 / 下0.14)
  ├─ 第三人称手电: 玩家眼位 + 玩家视线(世界锚定)
  ├─ 枪灯: MuzzlePoseCapture 枪口视图空间矩阵 → 相机旋转共轭回世界
  └─ LightBuffer.upload(≤2灯) → SSBO binding=7
        ↓ 同帧
composite/composite1 直接读 layout(std430, binding=7) 的 lights[]
```

**SSBO 布局(唯一真源 `SpotlightBufferLayout.java`,GLSL 镜像在 `lib/taclight_common.glsl`)**:
头 16B(lightCount/vlIntensity/flags/reserved)+ 每灯 96B = 6×vec4:
`posRadius(world xyz + 半径)` / `colorIntensity` / `dirType(world 归一方向 + 类型)` /
`cone(cos外,cos内)` / `vlParams(g各向异性, 密度, 束强度)` / `cookie(GLSL→Java 回写诊断)`。

**位布局由两份契约从两侧钉死**:`SpotlightBufferLayoutContract` + `UploaderSemanticContract`,
改布局必须同时过这两道门。

### 3.2 渲染管线(pass → 输出 buffer)

| Pass | 内容 | 写入 | 备注 |
|---|---|---|---|
| gbuffers_* | albedo→c2.rgb, 八面体法线→c1.xy, lm→c1.zw, 视图位置→c3.rgb, 遮挡系数→c3.a | c1,c2,c3 | 遮挡系数分类在 block.properties |
| composite | M1 表面照明:深度反投影重建位置 → 锥软边(smoothstep)×D6衰减×GGX×SSO遮挡 | c0 | SSBO 驱动 |
| composite1 | M3 体积光束:24 步 raymarch × HG 相位(g=0.55)× IGN 抖动,深度遮挡 | c4 | 与表面同一套锥/衰减数学 |
| composite2 | bloom 一级(4tap 软阈值,1:1)+ 曝光(锁定/自适应 8×3 网格,history c7) | c1,c7 | TACLIGHT_EXPOSURE_LOCK=1 当前锁定(A/B 用) |
| composite3 | bloom 二级(13tap 圆环大半径) | c2 | c1/c2 是 G-Buffer 槽位复用(照明后已消费) |
| final | c0+c4+bloom 合成 → ACES → split-tone → 暗角 → 颗粒;DBG 2/4/5/6 早退直出 | 屏幕 | 曝光读 c7(0.5,0.5) |

buffer 格式/复用声明集中在 composite.fsh 头部注释(Iris 注释常量)。

## 4. 铁律与关键设计决策(改代码前必读)

1. **坐标语义(铁律 3)**:SSBO 上传一律 **world 坐标**;scene-relative 转换只允许发生在消费侧,
   且必须走 `taclight_world_to_scene → taclight_scene_to_view` 两级封装。禁止内联坐标换算
   (v0.8.4 曾把 world 直接乘 R-only 的 gbufferModelView,灯飞到几百格外)。
2. **上传挂渲染帧不挂 tick**:20Hz 上传会让灯滞后相机最多 50ms,转视角拖拽可见。
3. **包内禁止声明 bufferObject.7**:那会让 Iris 自建同名缓冲覆盖模组绑定(铁律 2)。
4. **shaders.properties ASCII-only;#include 独占一行且行尾无注释**(实机翻车两次)。
5. **深度/遮挡比较一律在视图空间线性距离上做**(热修 13):设备深度差随距离二次缩小,
   固定阈值必然漏检。
6. **漏声明 uniform = Iris 静默禁用整包**(热修 14):GLSL 编译失败不报错,日志搜 GlShader。
7. **bloom 链全屏 1:1**(热修 15):半分辨率技巧在 Oculus 1.8.0 出现错位叠加,已退役,勿复活。
8. **第一人称同轴豁免**:灯锚眼睛时 SSO 必然假消光(黑边),vis 恒 1;第三人称走真 SSO。
9. **机位名一律下划线风格,命令参数用 string()**:brigadier word() 拒 '@' 且只消费前缀不抛错。
10. **代码红线**:0 行照搬 iterationT/Photon/旧项目(只允许公开数学与官方常量);
    实机视觉证据只允许真机截图(禁止 mock 假图);不新增编号文档。
11. **JDK17 构建**:一律走 `gradlew-java17.ps1`(PATH 无裸 java)。
12. **TDD 纪律**:行为变更先写契约/自测(红)再实现(绿);几何/布局/数学的回归全部用契约钉死。

## 5. 调试环境使用手册(日常开发循环)

**改动类型决定热重载路径**:

| 改了什么 | 流程 | 耗时 |
|---|---|---|
| 纯 GLSL(pack/) | `gradlew-java17.ps1 syncShaderPack` → 中继 `!reload` → 日志见 `Creating pipeline` | ~14s |
| Java | 重启:`session.ps1`(文件重定向!)| ~30s READY |

**启动会话**(坑位 12:禁止管道,Start-Process 子树继承写句柄会挂死终端):
```
powershell -NoProfile -ExecutionPolicy Bypass -File tools/session.ps1 > tools/.session/launch.log 2>&1
```
preflight 自动归档旧日志、强制 options.txt(maxFps=260 / vsync=false / **pauseOnLostFocus=false**)、
QuickPlay 进 `test` 存档、就绪后置顶聚焦。session.ps1 自身 ~30s 返回。

**文件命令中继**:把命令写进 `run/taclight-cmds.txt`(每行一条,2Hz 轮询,执行后清空):
- `/taclight kit` 发手电+枪灯附件;`/taclight cam goto wall_front|bloom_inside|...` 传机位;
- `/taclight scene <preset>` 建场景(幂等,重复 = blocks=0);`/taclight scene verify <preset>`
  逐格验收(权威行 `SCENEVERIFY ... mismatch=0 OK`,不符时指名坐标);
- `!reload` 真热重载(反射 Iris.reload();**mc.reloadResourcePacks() 是假的**,Oculus 不重建管线);
  `!diag` 诊断转储(版本/灯态/SSBO dump/cmdtree);`!bench` 3s 帧率基准;`!light`/`!neon`/`!gun` 开关。

**截图与量化判定**:
```
tools/drive.ps1 -Action shot -OutFile x.png          # CopyFromScreen,无需前台
tools/acceptance.ps1 side  -A x.png                  # 光斑质心须在准星右手带 [0.49,0.58]
tools/acceptance.ps1 align -A final.png -B dbg4.png  # 两图亮斑质心偏差 ≤ 5%/8%
node tools/imgdiff.js a.png b.png -o heat.png        # 差分 bbox/热图;griddiff/clusterprobe/stylemetrics 同目录
```
所有判定权威串:`TACLIGHT-ACCEPT PASS/FAIL`、`TOOLS-SELFTEST PASS`。

**调试视图**:改 `pack/shaders/lib/taclight_debug.glsl` 的 `TACLIGHT_DBG_STRIP`(0 正常画面,
1 法线审计盒,2 遮挡热图,3 SSO 掩码,4 体积光单独,5 bloom 链单独,6 线性深度)→ sync + !reload。
**拍完记得改回 0 并再 reload。**

**SOP-1 标准验收环(实测 ≈3 分钟)**:改 GLSL → sync → !reload → 同机位截图×2 →
imgdiff/griddiff/stylemetrics/acceptance 判定 → 结论进证据包。

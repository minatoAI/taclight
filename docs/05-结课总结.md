# TacLight 项目结课总结

> MC 1.20.1 + Forge 47.1.3 + Java 17 | Oculus 1.8.0 + Embeddium + TaCZ 1.1.8-hotfix + iterationT 3.2.0
> 目标:提供“手电筒/聚光灯”式锥形照明设备(非游戏内点光源),与 TaCZ 联动(照明设备)。

## 一句话成果
**两个锥形聚光灯设备(手持手电筒 / TaCZ 战术枪灯)已实现并经官方 G 通道点亮;
SSBO 直通通道的完整工程与调查记录已就位(现状被 Oculus 转换层阻挡,已封存)。**

## 关键决定(为什么这样)
1. 兼容性=通道选择(官方 Provider 最通用、SSBO 最强需包配合、自渲染仅无光影);
2. 边界:不做真投影阴影(需 Oculus 内部)、不做任意包全兼容、无光影不做块照明;
3. 软依赖:mixin 级门控插件 + 反射工厂,任何核心模组缺失均可降级启动;
4. 测验分层:纯 JVM 契约(ABI/数学/判定)与实机冒烟分离。

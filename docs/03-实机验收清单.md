# TacLight 实机验收清单

> 环境:runClient;选中光影包 "iterationT 3.2.0 (taclight)";夜晚/洞穴场景

## A. 手电筒(G 通道)
- [ ] 创造搜索 "手电筒"(或 /give @s taclight:flashlight),手持
- [ ] 对墙:出现锥形光斑(软边、随视线转向)
- [ ] 按 L:熄灭;再按:点亮(日志: handheld flashlight ON/OFF)

## B. 枪灯(S 通道,SSBO)
- [ ] 枪匠台合成 "战术枪灯"(8 铁锭+3 红石)或创造搜索 "Gun Light"
- [ ] 手持 HK416D + 改装界面安装灯(枪管下方出现灯模型 + 白色光束线)
- [ ] 日志出现:gun light ON (tacz:hk416d | taclight:gun_light)
- [ ] 墙面出现锥形光——此光仅由 TacLight SSBO 提供(枪不是发光物品)
- [ ] 转动视角:枪口朝上时光斑朝上;日志出现 muzzle capture armed(枪口模式)
- [ ] 拆下灯:光灭(日志 gun light OFF)

## C. 光束与高光
- [ ] 黑暗中对着天空/雾/雨:可见体积光束(光柱)
- [ ] 湿润表面或金属:可见高光点

## D. 遮挡
- [ ] 将方块置于光锥中:柱后无光(屏幕空间遮挡)

## E. 降级
- [ ] 无光影包(关闭 shaders):物品仍存在、不崩溃、无真实照亮
- [ ] 无 TaCZ 启动:模组仍加载(日志 TaCZ not detected: gunpack & gun-light integration disabled)
